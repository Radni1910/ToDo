# Todo App 

A simple Todo application built with HTML, CSS, and JavaScript.
Uses Firebase Firestore as backend for storing tasks.

## Features
- Add Todo
- Edit Todo
- Delete Todo
- Mark Complete
- Progress Bar
- Firebase Firestore backend

## Setup
1. Clone the repo
2. Create a Firebase project
3. Enable Firestore (Test mode)
4. Replace Firebase config in `todo.js`
5. Open `index.html` in browser (or use Live Server)

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Firestore

**Add your Firebase config before running.**
